# Examples of Quarto Manuals in Action

This folder contains examples of Quarto Manuals in action. Each example is a
Quarto project that demonstrates how to use the Quarto Manual framework to
create executable, flexible, and scalable operator documentation for a specific
workflow. The levels increase in operational and state-transition complexity,
not in the amount of explanatory prose.

Read `index.qmd` in this folder for more information.
