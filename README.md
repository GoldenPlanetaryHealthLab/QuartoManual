# Quarto Manual

This is not the project output.
This is the operating manual for assembling the conditions under which project work can run reproducibly.

## Flight-manual analogy

A flight manual does not fly from A to B.
It checks that the aircraft, crew, instruments, route, fuel, communications, and emergency procedures are ready.
The pilot still flies the plane.

## Quarto Manual analogy

A manual does not replace the scientific project.
It checks that the project directory, inputs, environment, scripts, tests, and execution tools are ready.
The researcher still does the science.
